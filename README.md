# 💻 ІнфоКлас — навчальна система для уроків інформатики

Хмарний сервіс для вчителя й учнів: навчальна траєкторія, інструкційні картки з покроковою фіксацією,
пояснення від вчителя «до рядка», розсадка за комп'ютерами, режим демонстрації та Lockdown-кіоск для ПК класу.

## Що вміє

### Учень (у класі та вдома)
- **Вхід за логіном і паролем, які генерує вчитель** (на кшталт `tiger47`, без e-mail). Загубив — вчитель видає новий за 1 клік.
- **«Мій шлях»**: курс → теми → уроки. Для кожної теми: *що вчимо* і *навіщо*. Кожен урок має позначку:
  ⭐ вміє (підтвердив вчитель) · ✋ виконав сам · 👥 у групі (спостерігав) · ◐ частково · 💤 був, але не працював · ✗ пропустив · 🚨 урок не відбувся.
- **«Треба наздогнати»**: пропущені уроки, уроки, зірвані тривогою, і роботи, зроблені лише «в групі».
- **Урок**: мета «Сьогодні я навчуся…», «Навіщо це мені», критерії успіху, матеріали (конспект, відео, зображення, YouTube, файли).
- **Інструкційна картка в покроковому режимі**: поточний крок великий, наступні приглушені. Учень ставить ✓ після кожного кроку,
  тож не вийде «проскочити» інструкцію. Можна показати всі кроки разом.
- **📌 «Поверх усіх вікон»**: маленьке вікно з поточним кроком і кнопкою «✓ Виконав» над Word, Scratch тощо
  (у кіоску; у Chrome/Edge через Document Picture-in-Picture).
- **❓ «Пояснення» біля кожного кроку**: спершу учень бачить пояснення, які вчитель уже писав іншим (найкращі за ⭐ зверху).
  Якщо не допомогло, тисне «Запитати вчителя», і відповідь приходить у спливному вікні. Учень оцінює пояснення зірочками,
  а історія його запитань зберігається.
- **🏁 «Я закінчив»**: самооцінювання за критеріями (🟢🟡🔴), рефлексія («що було найскладніше?»), **знімок екрана** →
  вчителю надходить сповіщення.
- **📂 Особиста робоча папка** (у кіоску): *Документи › InfoKlas › Учень › Урок*. Туди автоматично копіюються файли для роботи,
  які додав вчитель (приклади документів, електронні таблиці, заготовки). Учень зберігає туди результат, і «Я закінчив» сам надсилає вчителю
  нові та змінені файли. Удома ті самі файли можна завантажити й надіслати результат через сайт.
- **🔗 Посилання від вчителя** відкриваються самі (у кіоску — у його вікні, бо браузери під час уроку заблоковані) і лишаються на сторінці уроку.
- **Домашнє завдання** (здача тексту або файлу), **оцінки з коментарями**, **критерії оцінювання**.
- **🧠 Тренування**: інтервальне повторення (коробки Лейтнера) з питань пройдених уроків.

### Вчитель
- **Класи та учні**: масове створення списком («Прізвище Ім'я» на рядок), друк карток з логінами й паролями, журнал входів (з класу / з дому, ПК, IP).
- **Програма**: курси → теми (мета, навіщо) → уроки (мета, критерії успіху, конспект, кроки, матеріали, питання для тренування, ДЗ).
  Кроки можна імпортувати з **DOCX** (кожен пункт списку стає кроком) або вставити текстом.
- **Урок наживо** (`▶ Почати урок`):
  - **присутність** (✅ ⏰ ❌); учень, який увійшов за ПК, відмічається автоматично;
  - **кількість комп'ютерів** і **🔀 автоматична розсадка**: за клавіатуру першими сідають ті, хто найменше працював руками
    і хто пропустив минулий урок; групи змішуються за рівнем, вчорашні пари не повторюються; розсадку можна змінити перетягуванням;
  - **🔄 Поміняти ролі** водій ⌨️ ↔ штурман 🧭 посеред уроку;
  - кожен ПК показує, хто за ним сидить, прогрес кроків, 🙋 запитання, ✅ завершення та ⚠️ вихід з вікна демонстрації;
  - **режими**: 🛠 Практична · 📽 Презентація (PDF, зображення, відео синхронно на всіх ПК; вчитель гортає стрілками) ·
    📺 Мій екран (трансляція екрана вчителя через WebRTC) · 👀 Увага! (усі екрани заблоковані);
  - **🚨 Тривога — перервати**: урок позначається як перерваний, прогрес зберігається, учні отримують сповіщення, що можуть доробити вдома.
    Можна також записати урок, який не відбувся взагалі.
- **📂 Папка учня в журналі**: копія документів з комп'ютера учня (синхронізується щохвилини), перегляд Word/PDF/зображень/коду прямо в браузері, ZIP.
- **🔗 Відкрити посилання** на всіх або вибраних ПК (наприклад, тест). **Режим тесту**: вікно на весь екран, учень не може його закрити, закриваєте ви.
- **📤 Файли учням** під час уроку: вони одразу з'являються в робочих папках учнів. **⬇ Роботи (ZIP)**: усі файли та знімки екрана класу, по папках учнів.
- **Відповідь на запитання** просто з робочого місця: нове пояснення або вже наявне одним кліком.
  Одна відповідь закриває однакові запитання кількох учнів.
- **📊 Журнал**: учні × уроки з дати проведення, стани ✋/👥/💤/✗, оцінки, кількість разів «за клавіатурою», експорт CSV.
  Клік по клітинці показує кроки, скриншот, самооцінку й рефлексію; там же можна підтвердити ⭐ «вміє» / ⚠️ «не вміє» і поставити оцінку (1–12).
- **Сповіщення** (у браузері та звуком): запитання, завершені роботи, здане ДЗ, виконання вдома, розблокування ПК.

### Чому саме так (педагогіка)
| Прийом | Де в системі |
|---|---|
| Видимі цілі навчання й критерії успіху (Hattie, *visible learning*) | Мета, «навіщо», критерії на початку кожного уроку |
| Зменшення когнітивного навантаження, scaffolding | Покроковий режим: один крок за раз, закріплений крок поверх вікон |
| Формувальне оцінювання й самооцінювання | 🟢🟡🔴 за критеріями, рефлексія (exit ticket), коментарі до оцінок |
| Mastery learning | Окремо «виконав» і «вміє (підтверджено)»; список «Треба наздогнати» |
| Парне програмування водій/штурман | Розсадка, ротація ролей, облік «за клавіатурою» |
| Retrieval practice та інтервальне повторення | 🧠 Тренування з коробками Лейтнера |
| Взаємонавчання та «банк пояснень» | Пояснення зберігаються до кроку, учні оцінюють їх ⭐, найкращі показуються першими |
| Стійкість до зривів (тривоги, пропуски) | Робота вдома зараховується, а зірвані уроки потрапляють у «Треба наздогнати» |

> 📘 **Інструкції з ілюстраціями** для адміністратора, вчителя та учня (онлайн і PDF для друку) — [docs/](docs/README.md).

## Швидкий старт

Потрібен **Node.js 22.5+**.

```bash
npm install
```

```bash
TEACHER_LOGIN=teacher TEACHER_PASSWORD='змініть-мене' npm start
```

Відкрийте http://localhost:3000. Під час першого запуску створюється обліковий запис вчителя
(типово `teacher` / `teacher123`, **змініть його в ⚙️**), демо-курс «Інформатика. 6 клас» і клас 6-А з 6 учнями.
Дані зберігаються в `data/` (SQLite + завантажені файли). Резервна копія — це просто копія теки `data/`.

### Розгортання в хмарі
```bash
docker build -t infoklas .
```
```bash
docker run -d -p 3000:3000 -v infoklas-data:/data -e TEACHER_PASSWORD='надійний-пароль' --restart unless-stopped infoklas
```
Підійде будь-який VPS (Hetzner, DigitalOcean, Hostinger тощо) або Render/Railway/Fly.io з постійним диском.
**Обов'язково потрібен HTTPS** (наприклад, Caddy або nginx + Let's Encrypt), інакше браузер не дозволить
демонстрацію екрана, знімки екрана та вікно «поверх усіх вікон». Зворотний проксі має пропускати WebSocket.

Приклад `Caddyfile`:
```
infoklas.vasha-shkola.ua {
  reverse_proxy localhost:3000
}
```

## 🔒 Кіоск (Lockdown) для комп'ютерів класу

Веб-сторінка сама не може заборонити учню відкрити інший браузер чи гру, тому для ПК класу є окремий клієнт `kiosk/` (Electron):

- **стартує сам в обліковому записі учня `uchen`** (заблокованим), **розблоковується, коли вчитель натискає «Почати урок»**, і знову блокується після «Завершити урок». Облікових записів інших вчителів це не стосується. Запасний варіант — ручний запуск через **Veyon** → «Запустити програму» (`... --open`), тоді після уроку кіоск закривається (див. [DEPLOY-WINDOWS.md](DEPLOY-WINDOWS.md), крок 4);
- якщо учень перезавантажив ПК чи закрив кіоск посеред уроку — вчитель отримує сповіщення;
- розблоковується лише **одноразовим кодом вчителя** (🔒 Комп'ютери → «Код розблокування»; діє N хвилин і лише один раз),
  кнопкою «🔓 Розблокувати ПК» з уроку або **офлайн-кодом** (HOTP), якщо немає інтернету;
- у режимах Презентація / Мій екран / Увага! вікно стає повноекранним, завжди поверх інших і повертає собі фокус;
- під час уроку **закриває заборонені програми** (список у ⚙️: chrome.exe, steam.exe, minecraft…);
- у режимі практичної дає працювати в інших програмах, а крок інструкції показує поверх усіх вікон;
- «Я закінчив» робить знімок усього екрана без додаткових запитань;
- номер ПК передається автоматично, тож система знає, хто за яким комп'ютером.

### Збірка та встановлення
```bash
cd kiosk && npm install && npm run dist
```
Інсталятор з'явиться в `kiosk/dist/`. Встановіть його на кожен учнівський ПК. Під час першого запуску вчитель вводить адресу сервера,
номер ПК і свій логін і пароль (лише один раз).

### Обов'язково: політики Windows
Жодна програма не може сама заблокувати `Ctrl+Alt+Del` і Диспетчер задач, це робить Windows. Для надійного Lockdown:
1. Учні працюють під **звичайним (не адміністраторським) обліковим записом** Windows.
2. Через `gpedit.msc` (Конфігурація користувача → Адміністративні шаблони → Система → Параметри Ctrl+Alt+Del) увімкніть
   **«Видалити диспетчер завдань»**, а також «Видалити блокування комп'ютера» / «Видалити зміну пароля».
3. Додатково (найнадійніше): **Shell Launcher / Assigned Access** (Windows Pro/Education), де оболонкою учнівського облікового запису стає InfoKlas Kiosk.
4. Заборонені програми краще прибрати й через **AppLocker** або Software Restriction Policies. Кіоск лише страхує.

### 🐧 Linux Mint (зокрема старі двоядерні ПК)
Кіоск працює і в Linux Mint 21/22 (64-біт). Тут він теж закриває заборонені програми (`firefox`, `chrome`, `steam`…),
на час блокування й демонстрації вимикає системні комбінації клавіш:
Alt+Tab, Super (меню), Ctrl+Alt+T (термінал), Ctrl+Alt+Del, Alt+F4. Підтримуються Cinnamon, Xfce і MATE.
Після розблокування в режимі практичної комбінації повертаються, щоб учні могли перемикатися між програмами,
а після закриття кіоску — повністю відновлюються (навіть якщо ПК вимкнули аварійно — під час наступного входу учня).
Запуск через Veyon: `infoklas-kiosk --open`.

```bash
cd kiosk && npm install && npm run dist:linux
```
На кожному учнівському ПК від імені адміністратора:
```bash
sudo bash setup-mint.sh infoklas-kiosk_1.3.0_amd64.deb
```
Скрипт `kiosk/linux/setup-mint.sh` встановлює кіоск і створює обліковий запис учня `uchen` без прав адміністратора.
Він також забороняє Ctrl+Alt+F1…F6 (вихід у текстову консоль) і Ctrl+Alt+Backspace та вимикає гостьовий сеанс.
Кіоск стартує сам під час входу в `uchen` (заблокованим). За бажанням: `--autologin` — автовхід в обліковий запис учня, `--no-autostart` — лише ручний запуск.

**Старі ПК:** беріть **Linux Mint Xfce Edition** (найлегша), бажано від **2 ГБ RAM** (кіоск ~250–350 МБ, LibreOffice ще ~300 МБ),
64-бітний процесор (Core 2 Duo, Pentium Dual-Core, Athlon 64 X2 підходять). SSD замість HDD дає найбільший приріст швидкості.
Mint за замовчуванням використовує X11 — це потрібно для знімків екрана з кіоску (у Wayland не працюватиме).

Без кіоску система повністю працює в звичайному браузері. Тоді в ⚙️ «Номер цього комп'ютера» один раз задайте номер для кожного ПК.
Під час демонстрації браузер тільки повідомляє вчителю (⚠️), що учень залишив вікно, але не блокує це.


## Безпека та приватність
- Паролі зберігаються як хеш scrypt. Паролі **учнів** додатково зберігаються у відкритому вигляді **лише для вчителя**
  (щоб передрукувати картку). Якщо для вашої школи це неприйнятно, приберіть поле `pw_plain` і користуйтеся кнопкою «Новий пароль».
- Знімки екранів учнів доступні тільки вчителю.
- Трансляція екрана (WebRTC) у межах шкільної мережі йде напряму між ПК і не навантажує сервер.

## Що можна додати далі
- кілька вчителів і кілька кабінетів (зараз один вчитель і один комп'ютерний клас);
- конвертацію PPTX → PDF на сервері (LibreOffice);
- TURN-сервер для трансляції екрана поза локальною мережею;
- експорт оцінок в електронний журнал школи.
